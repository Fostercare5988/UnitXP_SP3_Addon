# UnitXP_SP3_Addon (ADDON ONLY)
WoW Vanilla 1.12 Lua Addon for supporting UnitXP SP3 mod

Backup of the last fully worked version from [UnitXP SP3 mod](https://github.com/allfoxwy/UnitXP_SP3)


Requires the [UnitXP SP3 native extension](https://github.com/brues-code/UnitXP_SP3); this portfolio targets build 90. Install this folder as `Interface/AddOns/UnitXP_SP3_Addon`. Restart the client after a DLL update. Original GPLv3 terms and source notices remain.
